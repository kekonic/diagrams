# Interface ball and socket are nodes

A provided contract is a ball and a required contract is a socket, because a rounded interface box does not show which side offers the contract. `role: provided` and `role: required` on an `interface` select those shapes. The glyphs are ordinary nodes, and the assembly is a `..>` dependency between the socket and the ball. They are not welded to a component or hexagon face — that second attachment system would fight surround layout, and the ports-and-adapters poster keeps boxed interfaces. The socket opens east so a left-to-right diagram meets the cup on its flat side and leaves through the arc; it does not turn toward a neighbor. PlantUML's socket syntax never landed reliably, so this follows the UML meaning rather than that glyph.
