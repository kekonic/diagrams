# Support

Report bugs and feature requests in the
[KDiagram issue tracker](https://github.com/kekonic/diagrams/issues). Include the KDiagram
extension version, editor name and version, operating system, and a minimal `.kdiagram` example
when possible.

Security vulnerabilities should follow the repository's
[security policy](https://github.com/kekonic/diagrams/security/policy) rather than being
reported publicly.
