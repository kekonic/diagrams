Model document databases with nested fields, access paths, indexes, and invariants. `profile` selects a constraint pack for CouchDB, MongoDB, DynamoDB, Cosmos DB, or Firestore. Each pack checks the partition key, cross-partition reads, atomic commit, and read audience that product actually has. Shared checks still require an index, real fields, and agreeing scopes.
